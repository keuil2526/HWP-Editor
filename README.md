# hwpedit — Linux HWP/HWPX 편집기 (시험판 0.9.13)

GTK4/libadwaita 네이티브 편집기. 문서 엔진은 [rhwp](https://github.com/edwardkim/rhwp)(MIT)이고,
그 위에 **파일 무결성 계층**을 직접 둡니다.

## 구조

| crate | 역할 |
|---|---|
| `crates/core` | 무결성 계층. 내용 기반 형식 판별, 미편집 문서 재직렬화 금지, 형식 변경 차단, 저장 전 재파싱 검증, 백업, 원자적 저장, 읽어서 확인, 외부 변경 감지. rhwp에 의존하지 않음 |
| `crates/engine` | rhwp `DocumentCore`의 타입 어댑터. 렌더·히트테스트·캐럿·편집·직렬화를 담당하며, **rhwp가 손실을 보고하면 저장 거부** |
| `crates/verify` | 라운드트립 측정 CLI (`hwpedit-verify OUT_DIR FILE...`) |
| `crates/app` | GTK4/libadwaita 편집기 (`hwpedit`) |
| `tools/` | rhwp와 독립적인 Python 구조 비교 도구 (`hwpdiff.py`, `survey.py`, 표준 라이브러리만 사용) |

## 빌드

필요 패키지 (Ubuntu 26.04):

```bash
sudo apt install libgtk-4-dev libadwaita-1-dev libgraphene-1.0-dev
```

rhwp를 `vendor/`에 받습니다. 검증한 커밋은 `1a76570e` (v0.8.7)입니다.

```bash
git clone https://github.com/edwardkim/rhwp.git vendor/rhwp && git -C vendor/rhwp checkout 1a76570e
```

`patches/`의 rhwp 수정을 적용합니다.
- `0001`: 문단 맨 앞에 입력할 때 구역 정의가 밀리지 않게 합니다. 적용하지 않으면 한글이 용지 설정(가로 등)을 무시합니다.
- `0002`: 표 셀의 화면 위치를 편집기에 알려 줍니다.
- `0003`: 표 아래 문단의 저장 위치(vpos)를 표 높이만큼 띄우고, 편집한 표의 높이를 측정값으로 맞춥니다. 적용하지 않으면 표 아래에 만든 표가 앞 표 위에 겹쳐 저장됩니다. 새 표는 한글처럼 쪽 경계에서 나뉩니다.
- `0004`: 쪽 번호 매기기 명령(`insert_page_number_pos_native`)을 더하고, 새 번호 앞 쪽에도 쪽 번호를 그립니다(한글 2022 실측).
- `0005`: 수식·그림·각주 같은 개체 **뒤에** 글자를 넣는 명령(`insert_text_after_control_native`)을 공개합니다.
- `0006`: 수식의 두 글자 기호(`+-` `<=` `>=` `!=` …)를 ± ≤ ≥ ≠ 로 그립니다.
- `0007`: 표 셀 안 수식 넣기·고치기·지우기와, 셀에서 개체 뒤에 글자 넣기 명령을 더합니다.
- `0008`: 글자처럼 취급한 개체(수식 등) 뒤의 글자 묶음과 다음 줄들의 문서 위치가 한 칸씩 모자라던 것을 고칩니다(표 셀에서 캐럿·클릭이 한 칸 밀리고 문단 끝 캐럿이 셀 첫 줄로 튐).
- `0009`: 수식의 라틴 글자 폭을 실제 수식 글꼴(STIX Two Text) 값으로 잡고, 기울어진 글자 뒤 위첨자를 띄우고, 위·아래첨자를 함께 쓸 때 아래첨자를 위첨자 아래로 내립니다(`m_i`의 i가 m에 가려지고 대문자가 위첨자를 가리던 것).
- `0010`: 보기의 문단 부호·투명 선을 켜고 끄는 함수를 엽니다(화면 전용). 문단 위·아래 간격만 바꿨을 때도 그 문단부터 줄 위치(vpos)를 다시 이어, 간격이 화면과 저장 파일에 반영되게 합니다(구역 첫 문단의 위 간격은 한글처럼 첫 줄 vpos에 저장).
- `0011`: 새로 넣는 수식의 기준선(baseline)을 85% 고정 대신 수식 모양에서 계산하고(한글도 수식마다 계산), 수식이 줄 높이를 차지하면 그 줄 기준선으로 씁니다(표 셀에서 행렬 수식 아래쪽이 잘리던 것). 수식 스크립트의 `GAMMA`처럼 전부 대문자로 쓴 그리스 대문자를 기호로 그립니다.
- `0012`: 줄 단위 선택 사각형 함수(`get_selection_rects_native`)를 공개합니다(편집기의 선택 표시용).

```bash
for p in patches/*.patch; do git -C vendor/rhwp apply "../../$p"; done
```

빌드·테스트:

```bash
cargo build --release
```

```bash
cargo test --release -p hwpedit-core -p hwpedit-engine
```

표 편집 점검(표 만들기·Tab·줄바꿈·줄/칸 추가·합치기·크기 조절·되돌리기를 차례로 실행하고, 단계마다 격자·셀 상자·저장 후 재열기를 검사하며 쪽 그림을 남김):

```bash
cargo run --release -p hwpedit --example table_lab -- .tmp/lab
```

화면 점검(리본 탭마다 창을 2배 크기 PNG로 저장, Xvfb 필요. `clean`은 `~/.config`의 GTK 테마 없이):

```bash
scripts/ui-shots.sh dark
```

## 실행

```bash
./target/release/hwpedit 문서.hwp
```

- 단축키:
  - 파일: 새 문서 Ctrl+N · 열기 Ctrl+O · 저장 Ctrl+S · 다른 이름으로 Ctrl+Shift+S · 인쇄 Ctrl+P · 닫기 Ctrl+W
  - 입력: 쪽 나누기 Ctrl+Enter
  - 편집: 실행 취소 Ctrl+Z · 다시 실행 Ctrl+Shift+Z / Ctrl+Y · 모두 선택 Ctrl+A · 잘라내기·복사·붙여넣기 Ctrl+X/C/V
  - 찾기: 찾기 Ctrl+F · 바꾸기 Ctrl+H · 다음/이전 F3 / Shift+F3 (찾기 칸에서는 Enter / Shift+Enter)
  - 서식: 진하게 Ctrl+B · 기울임 Ctrl+I · 밑줄 Ctrl+U · 글자 모양 Alt+L · 문단 모양 Alt+T
  - 서식(한글과 같은 키): 글자 크게/작게 Ctrl+] / Ctrl+[ (작게는 Alt+Shift+R도) · 줄 간격 넓게/좁게 Alt+Shift+Z / Alt+Shift+A. 한글의 다른 글자 크게 키 Alt+Shift+E는 이 앱에서 수식 넣기입니다
  - 정렬(한글과 같은 키): 왼쪽 Ctrl+Shift+L · 가운데 Alt+Shift+C · 오른쪽 Alt+Shift+H · 양쪽 Ctrl+Shift+M (배분·나눔은 도구 상자 단추)
  - 표: 줄/칸 추가하기 Alt+Enter · 줄/칸 지우기 Alt+Delete · 표를 개체로 선택 Esc(셀 안에서) · 선택한 표 지우기 Delete
  - 보기: 확대·축소 Ctrl+= / Ctrl+- / Ctrl+0
- 선택: 끌기, Shift+클릭, Shift+방향키/Home/End
- 리본: 한글 2022의 구성을 따릅니다([docs/03-hwp2022-ui.md](docs/03-hwp2022-ui.md)). 한글에 있지만 아직 지원하지 않는 단추는 회색으로 자리만 두며, 누르면 그렇다고 알려 줍니다.
  - 메뉴 줄: 파일 · 편집 · 보기 · 입력 · 서식 · 쪽 · 보안 · 검토 · 도구 (탭 이름 옆 ˅는 그 탭의 메뉴) · 찾을 내용 · ^(리본 접기, 탭을 누르면 다시 펼침)
  - 지금 동작하는 단추: **편집** 오려 두기·복사하기·붙이기·모양 복사(Alt+C)·글자 모양·문단 모양·스타일(F6)·세로·가로·쪽 여백·단·그림·표·찾기·글자 바꾸기 / **보기** 축소·확대·100%·쪽 맞춤·폭 맞춤 / **입력** 도형(직사각형·타원·직선)·그림·표·수식(Alt+Shift+E)·각주·미주·책갈피·하이퍼링크·문자표(Ctrl+F10) / **서식** 스타일(바탕글·본문·개요 1·개요 2)·글자 모양·문단 모양·문단 정렬·개요(Ctrl+Insert)·글머리표(Ctrl+Shift+Delete)·문단 번호(Ctrl+Shift+Insert)·한 수준 증가/감소(Ctrl+Num −/+) / **쪽** 편집 용지(F7)·세로·가로·쪽 여백·머리말·꼬리말·쪽 테두리/배경·쪽 번호 매기기·새 번호로 시작·현재 쪽만 감추기·쪽 나누기·단 나누기(Ctrl+Shift+Enter)·단
  - 배율(%)은 상태 표시줄 오른쪽에 보입니다.
  - **표 디자인**·**표 레이아웃** (캐럿이 표 안에 있을 때): 표 만들기, 표 채우기(셀 배경 색), 테두리(고른 셀에 지금 테두리 종류·굵기·색으로), 테두리 종류·굵기·색, 위·아래에 줄 추가, 왼쪽·오른쪽에 칸 추가, 줄·칸 지우기, 셀 합치기·나누기, 너비·높이 조절, 표 지우기

## 지원 범위 (0.9)

- **열기**: HWP 5.x, HWPX. 확장자가 아니라 내용으로 형식을 판별합니다.
- **편집**: 본문 문단과 (중첩되지 않은) 표 셀의 텍스트 입력·삭제, Enter/Backspace로 문단 나누기·합치기, 방향키·Home·End, 한글 입력기(GTK IM).
  - 선택한 범위를 입력·삭제하면 그 범위를 바꿉니다. 선택은 본문 구역 하나 또는 셀 하나 안에서만 됩니다.
- **실행 취소**: 연속 입력·삭제는 한 단계로 묶이며, 최대 99단계까지 됩니다.
  - 처음 상태까지 되돌리면 "수정 안 됨"으로 돌아가므로, 그때 저장하면 파일을 다시 쓰지 않습니다.
- **글자 서식**: 글꼴, 크기, 진하게, 기울임, 밑줄, 취소선, 글자 색. 리본은 캐럿 위치의 서식을 표시합니다.
  - 선택한 범위가 있으면 그 범위에 적용합니다.
  - 선택이 없으면 다음에 입력하는 글자에 적용합니다(한컴과 같은 방식). 캐럿을 옮기면 취소됩니다.
  - 한글 글꼴에는 기울임꼴이 없으므로 화면에서는 기준선을 중심으로 약 12° 기울여 그립니다.
- **문단 서식**: 정렬(왼쪽·가운데·오른쪽·양쪽·배분·나눔), 줄 간격(%), 왼쪽·오른쪽 여백(pt), 첫 줄 들여쓰기·내어쓰기(pt). 선택한 모든 문단, 또는 캐럿이 있는 문단에 적용합니다.
- **수식** (Alt+Shift+E, 입력 › 수식): LaTeX 문법으로 입력하면 미리 보기와 함께 한글 수식 문법으로 바꿔 넣습니다. 문서에는 한글 수식으로 저장되어 어느 한글에서나 열립니다. 수식 바로 옆에 캐럿을 두고 열면 그 수식을 LaTeX로 고칩니다. 표 셀 안에서도 됩니다. 분수·근호·첨자·Σ∫lim·그리스 문자·화살표·괄호(\left…\right)·행렬·cases·\text 를 바꾸고, 바꾸지 못한 명령은 대화상자에 표시합니다.
  - 수식·각주 같은 개체 옆에서 ←/→는 개체 앞과 뒤에 한 번씩 멈추고, 개체 바로 뒤의 Backspace·바로 앞의 Delete는 개체를 지웁니다.
- **스타일·문단 머리**: 문서의 스타일 적용, 개요(「개요 N」 스타일), 문단 번호, 글머리표, 한 수준 증가·감소. 동작은 한글 2022에서 실측한 대로입니다(증가 = 위 수준, 개요 1에서 증가하면 바탕글). Ctrl+Insert는 한글처럼 개요 적용/해제입니다(복사는 Ctrl+C).
- **복사·붙여넣기**:
  - 같은 문서 안에서는 서식을 유지합니다(rhwp 내부 클립보드).
  - 다른 창이나 다른 프로그램과는 일반 텍스트로 주고받습니다. 줄바꿈은 문단 나누기가 됩니다.
  - 한 번의 붙여넣기는 실행 취소 한 단계입니다.
- **찾기·바꾸기**:
  - 본문과 (중첩되지 않은) 표 셀에서 찾습니다. 대소문자 구분을 고를 수 있습니다.
  - 모두 바꾸기는 실행 취소 한 단계입니다.
- **표 편집**: 같은 표 안에서 셀을 가로질러 끌면 셀 블록이 표시되고, 「셀 합치기」가 그 블록을 합칩니다. 표 명령은 각각 실행 취소 한 단계입니다.
- **표 안 이동**: Tab은 다음 칸, Shift+Tab은 이전 칸으로 갑니다. 마지막 칸에서 Tab을 누르면 줄을 하나 추가하고 그 줄의 첫 칸으로 갑니다(한글과 같음).
- **표 크기 조절** (한 번 조절할 때마다 약 1mm, 한글과 같은 283 HWPUNIT):
  - Ctrl+←/→: 칸 너비를 바꿉니다. 표 너비도 함께 바뀝니다.
  - Ctrl+↑/↓: 줄 높이를 바꿉니다.
  - Alt+방향키: 경계만 옮깁니다. 이웃 칸이 그만큼 줄거나 늘어서 표 크기는 그대로입니다.
  - 마우스: 칸 경계를 끌면 안내선이 보이고, 놓을 때 한 번에 적용됩니다. 안쪽 경계는 경계 이동, 바깥 오른쪽·아래 경계는 표 크기 변경입니다.
  - 표 오른쪽 아래 **모서리**를 끌면 표 전체가 비율대로 커지거나 작아집니다. 끄는 동안 새 외곽선이 점선으로 보입니다. 합쳐진 셀이 있는 표는 너비만 바뀝니다.
  - 「표 레이아웃」 탭에 너비·높이 줄이기/늘리기와 「너비를 같게」가 있습니다. 「셀 높이를 같게」는 오른쪽 클릭 메뉴에 있습니다.
  - 합쳐진 셀이 있는 표: 칸 너비는 조절할 수 있지만, 줄 높이 조절은 아직 안 됩니다(안내가 표시됨).
- **표 개체 선택·지우기**: 셀 안에서 Esc를 누르면 한글처럼 표 전체가 개체로 선택되고 조절점이 보입니다. 이때 Delete/Backspace는 표를 지우고, Ctrl+C/Ctrl+X는 표를 복사/오려 둡니다. Esc를 한 번 더 누르면 선택을 풉니다.
  - 표 지우기는 리본, 오른쪽 클릭 메뉴, 「줄/칸 지우기」 대화상자(Alt+Delete)에서도 됩니다. 실행 취소 한 단계입니다.
  - 복사한 표는 같은 문서의 본문 문단에 붙일 수 있습니다(서식·구조 유지).
- **새 문서**: rhwp에 들어 있는 한컴 빈 문서 서식으로 시작합니다. 처음 저장할 때 확장자로 형식(.hwp/.hwpx)을 고릅니다.
- **화면 그리기**: 쪽 그림은 백그라운드 스레드에서 만들어집니다. 입력은 그리기를 기다리지 않고, 다 그려질 때까지는 직전 그림이 보입니다. 글자가 빽빽한 쪽은 약 0.1초 뒤에 바뀝니다.
- **PDF·인쇄**: PDF는 rhwp의 벡터 출력(글자 포함)으로 만듭니다. 인쇄는 GTK 인쇄 대화상자를 쓰고, 프린터 해상도로 쪽을 그립니다.
- **저장**: 원래 형식으로만 저장합니다.
  - 편집하지 않았으면 파일을 다시 쓰지 않습니다. 다른 이름으로 저장할 때는 원본 바이트를 그대로 복사합니다.
  - 편집한 HWPX를 저장할 때는 확인을 받습니다.
  - 저장 직전에 원본과 저장 결과의 레코드(HWP)·요소(HWPX) 수를 비교해, 편집기가 다루지 못해 빠지는 요소가 있으면 경고합니다. 기본 선택은 「저장하지 않음」입니다.
  - 사용자가 직접 지운 표(와 그 안의 그림·도형)는 손실로 세지 않습니다. 지우기 직전과 직후의 저장 결과 차이를 기억해 두었다가 빼고 비교합니다. 실행 취소·다시 실행을 따라가고, 저장하면 초기화됩니다.
- **미지원**:
  - 다른 프로그램과 서식 있는 복사·붙여넣기 (현재는 일반 텍스트만)
  - 문단 위·아래 간격, 탭, 고정·최소 줄 간격 (기존 값은 보존하고, 리본에서는 비활성으로 표시)
  - 수식·중첩 표·글상자 안 찾기
  - 셀 크기·테두리·배경, 그림·도형·머리말·각주 편집
  - 중첩 표·글상자 안 편집

검증 결과와 알려진 손실은 [docs/01-roundtrip-poc.md](docs/01-roundtrip-poc.md)에 있습니다.
남은 작업과 단계별 계획은 [docs/02-plan.md](docs/02-plan.md)에 있습니다.

## 설치 패키지

```bash
scripts/build-deb.sh
```

`dist/hwpedit_<버전>_amd64.deb`가 만들어집니다. 의존성은 실제로 링크된 라이브러리에서 계산합니다.
- 들어 있는 것: 데스크톱 항목, 아이콘, HWPX MIME 정의(`application/hwp+zip`, `*.hwpx`)
- 설치: `sudo apt install ./dist/hwpedit_*.deb`

## 한글 2022 검증 (WinBoat)

`~/hwpedit-bridge/hancom-worker.ps1`(저장소 사본: `tools/hancom-worker.ps1`)을 Windows에서 실행하면 됩니다. 그러면 한글 공식 자동화(HwpObject)로 다음을 대신 처리합니다.
- 문서 열기
- 쪽 수·텍스트 추출
- PDF 출력
- 다시 저장

리눅스 쪽에서는 `python3 -I tools/hancom.py check OUT_DIR 파일...`로 결과를 비교합니다.
- 비교 항목: 열기 성공 여부, 쪽 수, 텍스트 유사도, 쪽별 화면 일치율(2px 허용 잉크 F1), 한글이 다시 저장한 파일을 우리 엔진이 여는지
- 한글 프로그램을 역분석하지 않고, 결과만 비교하는 기준(정답지)으로 씁니다.
- 화면 확인: `python3 -I tools/hancom.py ui OUT_DIR STEPS.json`으로 클릭·캡처 단계(`click`·`hover`·`maximize`·`shot` 등)를 실행합니다.
