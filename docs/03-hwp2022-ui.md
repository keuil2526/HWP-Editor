# 한글 2022 화면 구성 (따라 만들 기준)

WinBoat의 한글 2022(창 크기 1372×832, 배율 125%)를 `tools/hancom.py ui`로 눌러 가며 찍은 화면에서 옮겨 적었다.
캡처 원본은 `.tmp/hwp-ribbon/`와 `.tmp/hancom-tour/`에 있다(저장소에는 넣지 않는다).

표기: **[확인]** 캡처로 확인함 · **[미확인]** 아직 캡처하지 못함.

## 메뉴 줄 [확인]

`파일` | `편집˅` `보기˅` `입력˅` `서식˅` `쪽˅` `보안˅` `검토˅` `도구˅` | (표 안에서만) `표 디자인` `표 레이아웃˅` · · · `찾을 내용˅` `^`(리본 접기) `×`

- 탭 이름을 누르면 아래 리본이 바뀌고, 이름 옆 `˅`를 누르면 그 탭의 메뉴가 펼쳐진다.
- 표 안에 커서가 들어가면 `표 디자인`·`표 레이아웃`이 도구 다음에 나타나고, 표를 만든 직후에는 `표 디자인`이 선택된다.

## 아직 캡처하지 못한 것 [미확인]

표 레이아웃 탭, 파일 메뉴, 각 메뉴의 하위 메뉴, 작은 단추들의 이름(도움말 풍선).
파일 메뉴 캡처 때 도구 메뉴를 닫으려던 클릭이 메뉴 안의 「환경 설정」을 눌러 한글의 환경 설정 대화상자가 열렸다.
그 뒤 클릭 몇 번이 대화상자 안(하이퍼링크 색 선택, 「기타」 탭)에 들어갔고 「설정」은 누르지 않았다(캡처로 확인).
대화상자는 「취소」로 닫아야 한다. 다음 캡처 작업은 메뉴를 빈 곳 클릭이 아니라 같은 ˅를 다시 눌러 닫도록 바꿀 것.

없는 것은 아이콘 테마의 기호 아이콘(`sys:` 이름)을, 테마에도 없으면 문서 모양 아이콘을 쓴다.

(탭 전환, 편집˅·쪽˅ 메뉴, 리본 접기/펴기, 미지원 단추 알림, 표 격자로 3×4 표 만들기, 표 레이아웃의 아래에 줄, 배분 정렬, 쪽 나누기).
실제 데스크톱에서의 클릭은 **[미확인]**.
